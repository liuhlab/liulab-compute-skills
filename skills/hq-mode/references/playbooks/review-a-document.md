# Review a document

**You own a review the user can work through, and the user's text stays theirs.**

1. Commit the document as it stands.
2. Write the review in a separate file beside it. Never edit the document in place.
3. Numbered points, most important first. For each: the passage, the problem, the evidence, and
   the fix you recommend.
4. Discuss one point at a time. The user supplies the biology, you supply the check.
5. When a point lands, write the decision into the document, with no rationale, and delete the
   point from the review.
6. Keep the user's hand edits; never revert them.
7. At the end, delete the review file or promote what lasts to a permanent note.

**Reply:** points remaining, points landed, and the next one.
