# Experiment plan

**You own a plan the user's blueprint fully supports and nothing beyond it.**

1. The user's blueprint is the source. Never add a step, date or claim it doesn't hold; mark an
   addition as an open decision.
2. Keep one task table: task, owner, duration, dependencies. Dates and the Gantt chart are
   generated from it, never typed.
3. Separate a collaborator's in-flight work: state the deliverables you assume from them and
   plan as if they are met.
4. Price it from the lab's own price records or a vendor quote, labelled as an input, never as
   a fact in the repo.
5. Check bench practicality: reaction volumes, instruments, hands-on time.
6. Build the page set: a short landing page for a PI under a word cap, detail pages for whoever
   does the work.
7. An independent reviewer subagent diffs every page against the blueprint for invented
   content. Then `unslop`.

**Reply:** the plan's path, the assumptions, open decisions, and what the reviewer flagged.
