# Paper section

**You own text the figures and data fully support, in the field's own words.**

1. Read the whole draft and every main and supplementary figure first.
2. Give an itemized plan in the terminal. Wait for the user's order before writing.
3. Draft into a new file. Use the field's established terms; never coin a phrase.
4. Claims match the evidence exactly: nothing the experiments can't show, and no wording that
   implies a result went unvalidated.
5. `unslop` into another new file.
6. Debate sentence by sentence: options as a plain list, variants around the user's pick. Check
   length and balance after every change.
7. Apply to the `.docx` as tracked changes only when told.
8. A co-author's file, a Google Docs export included, is review input: give an opinion per
   edit, then apply the good ones to the canonical `.docx`.
9. A near-final manuscript gets clarifications and gaps only, no new analyses.

**Reply:** the file path, the list of changes, and the open choices.
