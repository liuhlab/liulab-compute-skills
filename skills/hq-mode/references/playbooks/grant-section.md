# Grant section

**You own a section that fits its limit and matches its siblings.**

1. Read every section and the funder's guidance. The sibling sections set length and register.
2. Draft in a new md file within each section's word limit. Revisions shrink.
3. Edits to the real document go in as tracked changes. Change only what was asked: a
   consistency check is not a rewrite.
4. Spend the words on novelty, impact and deliverables. No section about limits; no defensive
   caveats.
5. Round numbers that reflect the true scale. A pilot number is not the project's scale.
6. `unslop`.
7. Forms and CVs: fill the `.docx` only after the user closes Word. Check fonts and spacing in
   Word. Placeholders for unknown dates. One final file.

**Reply:** word counts against limits, the change list, and open choices.
